# Cómo convertir el video demostrativo en la entrega auténtica del equipo

El archivo `VIDEO_DEMOSTRATIVO_VOZ_SINTETICA.mp4` dura **4 min 30 s** y usa narración artificial. Es un ejemplo audiovisual, **no prueba participación de integrantes reales**. La consigna exige exposición original del equipo. Graben la versión definitiva con voces propias (y, si lo desean, cámaras) para cumplir ese criterio.

1. Completen los nombres en la portada de `presentacion/Proyecto_Final_Analisis_Salarios.pptx` y en README.
2. Revisen que comprenden las once diapositivas y los resultados. Ensayen el guion `GUION_VIDEO_POR_INTEGRANTE.md` con palabras propias, no leyendo mecánicamente.
3. Repartan participación real entre **2 o 3 estudiantes**. Opción para 2: expositor A diapositivas 1–5; expositor B diapositivas 6–11. Opción para 3: 1–4, 5–8 y 9–11.
4. Usen PowerPoint, OBS, Zoom o el grabador de pantalla para compartir presentación y Colab; muestren al menos un fragmento de código, un gráfico y el resultado del modelo.
5. Grabación ideal: **3:30–4:30**. La consigna solo acepta de **2:00 a 5:00**; verifiquen duración del MP4 antes de subir.
6. Exporten a MP4 y publiquen el archivo en `video/` de GitHub si el tamaño lo permite; también puede quedar en YouTube no listado con URL visible públicamente, siempre que el docente pueda entrar sin permisos.
7. Actualicen README para enlazar la grabación **definitiva** y, opcionalmente, retiren el MP4 sintético para que no haya confusión.
8. Comprueben el acceso desde incógnito. Cada integrante pega la misma URL pública de repositorio en Canvas.

**Sugerencia de cierre:** "No usamos salarios reales. Construimos datos sintéticos para demostrar limpieza, estadística y validación predictiva. Antes de aplicar este modelo en un sistema de nómina real necesitaríamos datos autorizados y validar riesgos de sesgo".
